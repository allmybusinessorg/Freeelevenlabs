**Creative Audio AI** is a free, open-source desktop application that provides unlimited, offline AI voice cloning and continuous speech generation. Powered by OpenBMB's **VoxCPM2** 2-Billion parameter engine, it allows creators, developers, and voice artists to synthesize 48kHz studio-quality voiceovers locally with **zero monthly subscription fees** and **zero data tracking**.

---

## 🌟 Key Features

- 🎭 **Zero-Shot Voice Cloning**: Clone any voice with continuous acoustic fidelity using a 3-second reference audio clip.
- 🎨 **Controllable Voice Design**: Instruct the AI in plain text to shape voice tone, age, accent, emotion, and tempo.
- ⚡ **Local GPU Acceleration**: Powered by PyTorch CUDA for 1-to-3 second voice synthesis on NVIDIA GeForce RTX GPUs.
- 🔒 **100% Offline Privacy**: Your voice samples, scripts, and generated audio never leave your local hard drive.
- ♾️ **Unlimited & Forever Free**: No character limits, no API credits, no paywalls.

## 🚀 Quick Start (Running Locally)

```bash
# 1. Clone this repository
git clone https://github.com/allmybusinessorg/Freeelevenlabs.git
cd Freeelevenlabs

# 2. Install dependencies
npm install

# 3. Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the web portal.
